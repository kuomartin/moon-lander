# Radar Moon Lander

這是一個為強化學習 (Reinforcement Learning, RL) 所設計的登月小艇 (Moon Lander) 環境，專為 **多層感知器 (MLP)** 訓練所打造。
本專案有別於傳統提供像素畫面讓卷積神經網路 (CNN) 學習的版本，而是使用了類似「雷達」的射線觀測系統，讓代理程式 (Agent) 可以透過多條發射射線來感知地形與周遭環境。

## 特色
* **雷達觀測空間**：代理程式可發出多條射線（預設 20 條），測量與地形、邊界或降落平台之間的距離與類別。此外還提供座標、速度、角速度、剩餘燃料、角度等資訊（共 `num_rays * 2 + 8` 個維度）。
* **多樣化地形與目標**：每次重置 (reset) 都會生成不同的地形，包含三種不同獎勵倍數的降落平台 (Pad 1, Pad 2, Pad 3)。
* **物理模擬**：包含重力下墜、主引擎推力以及左右旋轉的慣性計算。
* **Farama Gymnasium 標準介面**：實作了標準的 `reset()` 和 `step()` 方法，可無縫與 Stable Baselines 3 (SB3) 等強化學習函式庫整合。

## 觀測與獎勵
### 觀測空間 (Observation Space)
* **雷達資訊**：每條射線包含 `[距離, 類別]`。
    * 類別：`-1` 為地形或邊界，`1, 2, 3` 分別代表三種降落平台。
* **狀態資訊**：包含 `[x, y, vx, vy, v_angle, fuel, sin(angle), cos(angle)]`。

### 獎勵系統 (Reward System)
* **位移獎勵**：根據與最近平台的距離變化計算 Shaping Reward。
* **動作懲罰**：主引擎與副引擎的開啟會扣除微量分數與燃料。
* **穩定懲罰**：角速度過大會被扣分，鼓勵平穩飛行。
* **降落結果**：
    * **成功降落**：根據平台等級獲得大幅獎勵（`30 * mult^2`）。
    * **墜毀/出界**：扣除 100 分。

## 檔案說明
* `lander_env.py` - 主要的遊戲物理引擎與渲染環境（繼承自 `gymnasium.Env`）。
* `play_human.py` - 提供人類玩家試玩的腳本，用來熟悉環境與物理操作。
* `train.py` - 使用 PPO 演算法進行訓練與測試。
* `train_sac.py` - 使用 SAC 演算法進行訓練與測試（通常更適合連續動作空間）。
* `test_dual.py` - 雙視窗對比腳本，可同時載入兩個模型進行性能比較。
* `requirements.txt` - 環境需求套件清單。

## 預訓練模型與實驗
本專案包含多個不同配置的預訓練模型（儲存為 `.zip` 檔案）：
* **11 射線系列** (`11.zip`, `11_pro.zip`)：輕量級觀測配置，適合低運算需求。
* **21 射線系列** (`21.zip`, `21_pro.zip`, `21_sac.zip`)：平衡配置。`pro` 版本通常代表移除著陸容忍度 (No Tolerance) 的進階訓練版本，著陸精度更高。
* **31 射線系列** (`31.zip`)：高維度觀測配置。
* **SAC 版本** (`21_sac.zip`, `n21_sac.zip`)：使用 Soft Actor-Critic 演算法訓練的模型。

### 實驗結論摘要
根據 `專案報告.md` 的分析：
1. **21 射線** 是效能與學習穩定度的平衡點，成功率最高可達 **93%**。
2. **移除容忍度 (No Tolerance, NT)** 的訓練方式雖然讓初期學習較慢，但最終能讓 Agent 更傾向於挑戰高難度的 **Pad 3 (3 倍獎勵區)**，獲得更高的平均得分。
3. **過多觀測 (31 射線)** 反而可能引入雜訊，導致評論家 (Critic) 的預測準確率下降。

## 如何執行

1. **安裝相依套件**：
   ```bash
   pip install -r requirements.txt
   ```

2. **自行手動遊玩 (測試物理與畫面)**：
   ```bash
   python play_human.py
   ```
   **操作方式**：
   * `W` 或 `上方向鍵`：啟動主引擎 (抗拒重力往上飛)
   * `A` 或 `左方向鍵`：逆時針旋轉
   * `D` 或 `右方向鍵`：順時針旋轉
   * 降落目標：在最底部的白色平台上「平穩且端正」地降落即可獲得大幅度的獎勵。

3. **訓練強化學習模型**：
   * 使用 PPO：
     ```bash
     python train.py --timesteps 500000 --model-path my_ppo_model
     ```
   * 使用 SAC：
     ```bash
     python train_sac.py --timesteps 500000 --model-path my_sac_model
     ```
   * **參數說明**：
     * `--timesteps`: 總訓練步數。
     * `--resume`: 接續之前的模型訓練。
     * `--num-rays`: 雷達射線數量（預設 20）。
     * `--map-pool-size`: 固定的地圖池大小（若設為 10，則只會在 10 種隨機生成的環境中訓練，有助於過擬合測試）。
     * `--speed-tolerance`: 降落時允許的最大速度誤差（預設為 0，即最嚴苛；大於 0 則放寬判定並提供緩衝獎勵）。
     * `--angle-tolerance`: 降落時允許的最大角度誤差（預設為 0，即最嚴苛；大於 0 則放寬判定並提供緩衝獎勵）。

4. **測試已訓練好的模型**：
   ```bash
   python train.py --test --model-path my_ppo_model
   ```
   或者使用 SAC 腳本測試：
   ```bash
   python train_sac.py --test --model-path my_sac_model
   ```

5. **雙模型效能對比**：
   如果你訓練了多個模型，想看看哪一個表現更好，可以使用 `test_dual.py`。該腳本會**自動偵測**模型所使用的雷達射線數量：
   ```bash
   python test_dual.py 21_pro.zip 11_pro.zip --fps 60
   ```
   這會開啟兩個環境，讓兩個 Agent 在相同的種子 (Seed) 下進行降落比賽。
